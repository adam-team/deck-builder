# Старт за 10 минут

Для ученицы, которой нужна красивая презентация: урок, вебинар, КП, карусель или сторис. Программировать не нужно.

## 1. Что нужно

Компьютер, Google Chrome и Claude Code с подпиской (лучше самая новая Opus с усилием high). Для ссылки в интернете понадобится бесплатный Vercel.

## 2. Установка одним сообщением

Открой Claude Code в пустой папке и отправь:

```text
Склонируй репозиторий https://github.com/adam-team/deck-builder в папку deck-builder,
подготовь окружение по SETUP.md и сразу начни опрос по docs/agent-contract/WORKFLOW.md.
Я хочу презентацию с красивым дизайном и анимациями. Спрашивай по одному вопросу, с вариантами ответа.
```

Репозиторий приватный: сначала Куралай даёт доступ на GitHub.

## 3. Что будет дальше

1. **Тема:** для чего презентация, кто смотрит, где покажете.
2. **Структура:** агент спросит, есть ли план. Нет? Откроется **конструктор**: задача, формат, слайды по порядку, справа все слайды схемой.
3. **Дизайн и анимация:** **Дизайн-тека** с 56 видео: презентации листаются сами, видно 3D-переходы (куб, переворот, полёт камеры).
4. **Тексты:** агент спрашивает по каждому слайду.
5. **Готово:** живая презентация (стрелки, F на весь экран), PDF и картинки для Instagram.

## 4. Как отвечать

Цифрой варианта или своими словами, можно голосом. «Не знаю» тоже ответ: агент предложит черновик. Цифры и отзывы называешь только ты.

## 5. Если агент сбился

```text
Остановись. Прочитай CLAUDE.md и docs/agent-contract/WORKFLOW.md.
Скажи, на каком мы этапе и какие файлы в projects/ готовы. Продолжай по одному вопросу.
```
