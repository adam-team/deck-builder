# Структура

1. **Одна мысль = один слайд**, до 30 слов. Длинный абзац превращай в два слайда или в «Шаги».
2. **Ритм:** чередуй типы. После трёх текстовых слайдов поставь цифру, цитату или картинку.
3. **Разделы:** в презентации больше 12 слайдов разделы нужны, чтобы зритель понимал, где он.
4. **Формулы:**
   - урок: обложка → план → зачем → шаги → пример → практика → задание → призыв;
   - продажа: обложка → боль → было/стало → что внутри → шаги → цифра → отзыв → тарифы → призыв;
   - карусель: обложка-крючок → мысль → шаги → цифра → призыв (5-8 слайдов);
   - вебинар: обещание → кто я → план → 3 раздела → кейс → предложение → призыв.
5. **Конец всегда с действием:** кодовое слово, ссылка, задание.
