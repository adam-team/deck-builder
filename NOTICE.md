# Происхождение и атрибуция

**Deck Builder**: обучалка и агентский контракт для презентаций. Автор движка (`template/`), генератора, конструктора, галереи,
дизайнов 1-37 и презентаций в `designs/own/`: Куралай.

Формат агентского репозитория повторяет Site Builder и Platform Builder Куралай, адаптированные из **Reels Pipeline Automontaj**
(@saint4ai, onAI Academy), https://github.com/saint4ai/reels-pipline-automotaj, MIT. Скрипты сторожа секретов взяты оттуда.

Движки с GitHub в `engines/` распространяются под своими лицензиями (MIT): см. `THIRD_PARTY_NOTICES.md`.
Шрифты подключаются с Google Fonts (SIL Open Font License).
