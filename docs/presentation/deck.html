Первый вопрос: есть структура?

да, есть план
Текст урока, старая презентация, сценарий Агент режет материал на слайды и подбирает каждому тип из 16. Показывает список: «Так?»
нет плана
Собираем в конструкторе Задача, формат, слайды по порядку, кнопка «+ Добавить». Справа схема всех слайдов.
чат с агентом

«У тебя уже есть структура: план слайдов, старая презентация, текст урока или сценарий? 1) да, пришлю 2) нет, соберём в конструкторе 3) предложи сама»

Формулы порядка слайдов

задачапорядок
урокобложка → план → зачем → шаги → пример → практика → задание
продажаболь → было/стало → что внутри → цифра → отзыв → тарифы → призыв
каруселькрючок → мысль → шаги → цифра → кодовое слово (5-8 слайдов)
вебинаробещание → кто я → план → 3 раздела → кейс → предложение
питчпроблема → решение → цифры → план → команда → встреча

Каждая формула уже лежит в конструкторе: выбираете задачу — слайды подставляются.

Какой переход под задачу

задачапереход
урок, PDFfade · slide · convex: спокойно, внимание на мысли
вебинарcube · cards: держат внимание на экране
продажа, питчorbit · zoom: wow-эффект на ключевых слайдах
карусель, сторисslide · flip: как листают в телефоне

Правило: один переход на всю презентацию. Если смотрят на анимацию, а не на мысль, переход слишком сильный.
