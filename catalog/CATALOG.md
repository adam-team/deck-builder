## Как применять

- **tokens**: дизайн шаблона → design: номер в deck.json → python3 scripts/build_deck.py projects/<id> [--pdf]
- **own**: PDF-образец → взять стиль (цвета, шрифты, приёмы) в tokens/style deck.json ближайшей палитры (8 = стиль Куралай)
- **external**: движок с GitHub → reveal.js: python3 scripts/build_reveal.py projects/<id> --theme <тема>; impress.js: агент собирает по engines/impress/examples
