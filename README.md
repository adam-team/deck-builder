# Deck Builder: обучалка «Презентация с красивым дизайном и 3D-анимацией»

Репозиторий для **Claude Code** и **Codex**. Ученица отвечает на вопросы, агент вместе с ней собирает структуру, предлагает дизайны
и переходы в виде видео (как на YouTube), пишет тексты и выдаёт живую презентацию, PDF и картинки для Instagram.

> **Агенту:** подготовь окружение по [`SETUP.md`](SETUP.md) и начни опрос по [`docs/agent-contract/WORKFLOW.md`](docs/agent-contract/WORKFLOW.md).
> Один вопрос за раз, с вариантами. Новичку: [`START.md`](START.md).

## Как это работает

1. **Тема ⏸**: для чего, кто смотрит, где покажете, что зритель сделает в конце.
2. **Структура ⏸**: есть план — агент раскладывает его по 16 типам слайдов; нет — **конструктор** `structure/index.html`
   (9 задач: урок, продающая, вебинар, питч, карусель, сторис, кейс, мастер-класс, о себе; 4 формата; превью всех слайдов).
3. **Дизайн и анимация ⏸**: **Дизайн-тека** `gallery/index.html` — 56 видео, презентации листаются сами, видно переходы.
4. **Тексты ⏸** по слайдам.
5. **Сборка**: один HTML-файл с анимациями + PDF + картинки.
6. **Проверка ⏸** и **выдача ⏸**: PDF, ссылка на Vercel, картинки для карусели и сторис.

## Анимации и 3D-переходы

| Переход | Как выглядит |
|---|---|
| `fade`, `slide`, `zoom` | проявление, сдвиг, приближение |
| `convex` | 3D-поворот как страница книги |
| `cube` | слайды на гранях вращающегося куба |
| `flip` | слайд переворачивается как карточка |
| `cards` | стопка карточек: новый выезжает поверх |
| `orbit` | полёт камеры, как в Prezi |

Появление пунктов по клику: снизу, приближением, из размытия, слева. Плюс reveal.js (convex, concave, zoom) и impress.js (3D-холст).

## Что внутри

| Папка | Что |
|---|---|
| `CLAUDE.md`, `AGENTS.md`, `START.md`, `SETUP.md`, `CONTEXT.md` | входы и карта |
| `docs/agent-contract/` | `WORKFLOW.md` (этапы), `QUESTIONS.md` (вопросы) |

| `tools/` | запись видео-превью |

## Команды

```bash
bash scripts/new-project.sh my-lesson
open structure/index.html
open gallery/index.html
python3 scripts/catalog.py find карусель
python3 scripts/build_deck.py projects/my-lesson --pdf
bash scripts/export-images.sh projects/my-lesson
bash scripts/check-deck.sh projects/my-lesson/deck
```
